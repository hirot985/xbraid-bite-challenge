# XBRAID BITE! CHALLENGE

Mobile-friendly boat-jigging reaction game demo. Two rounds, mandatory animated guide, six fish species, manual reel taps, product introduction and daily shared rankings.

This GitHub Pages frontend uses a separate public ranking API and database. It does not expose the owner's private Site or its saved records. Ranking registration is optional and explicitly publishes the chosen nickname and reaction time. Scores use the API server's Japan date. Browser best scores stay on the device. Timing is client-measured, not competition-grade anti-cheat.

Official logo source: https://xbraidygk.jp/asset/images/common/logo.svg
Sample featured product: REAL dtex X8, https://xbraidygk.jp/products/realdtex/
Official product image: https://xbraidygk.jp/cms/wp-content/uploads/2017/05/realdtex.png

Game artwork is original POP-style illustration. This is a playable promotional concept sample, not an assertion of an official campaign or actual fishing results.

## Deployment
Static files at the root are served by GitHub Pages from main. `.nojekyll` preserves ES modules and assets. No private credentials, account identifiers, source-service tokens or ranking records are committed.
